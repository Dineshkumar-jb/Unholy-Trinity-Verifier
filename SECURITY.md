# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| `1.0.x` | ✅ Active Development |

## Reporting a Vulnerability

If you discover a security vulnerability or potential exploit within the smart contract (`CertificateNFT.sol`), API endpoints, or hashing implementation:

1. **Do not create a public GitHub issue.**
2. Please reach out privately to the lead developer:
   - **Dinesh Kumar JB:** Contact via GitHub at [https://github.com/Dineshkumar-jb](https://github.com/Dineshkumar-jb)
3. Include detailed steps to reproduce the issue, along with any relevant proof-of-concept code.
4. We will review and address valid reports promptly.
